## 1. Executive Summary

This document describes the end-to-end data flow of the [COMPANY] FinOps solution, built on the **Microsoft FinOps Toolkit (FinOps Hub)**. The solution collects Azure costs from Cost Management, processes them through Azure Data Factory, stores them in Azure Data Lake Storage Gen2 and Azure Data Explorer, and exposes them via a Power BI semantic model to the **"Reservations and Saving Plans Tracker"** report.

**Document objectives:**
- Document the complete architecture and data flow, layer by layer
- Identify data sources, transformations, and dependencies
- Provide a checklist for data correctness verification and source testing
- Support solution ownership transfer

### 2.2 Sequential Data Flow

**Path A — Cost data (ADF ingestion pipeline)**

Cost data follows a multi-stage pipeline before reaching Power BI. Each step is triggered automatically by the previous one.

| **Step**<br> | **Component**<br> | **Trigger**<br> | **What happens**<br> |
| --- | --- | --- | --- |
| 1<br> | Azure Cost Management<br> | ADF scheduled trigger (daily / monthly)<br> | Exports Parquet/CSV + `manifest.json` to ADLS Gen2 `/msexports/`<br> |
| 2<br> | ADF — `msexports_ExecuteETL`<br> | BlobEvent: `msexports_ManifestAdded`<br> | Schema mapping, EA/MCA channel detection, converts to Parquet Snappy<br> |
| 3<br> | ADLS Gen2 `/ingestion/`<br> | Output of step 2<br> | Stores processed Parquet files + `manifest.json`<br> |
| 4<br> | ADF — `ingestion_ExecuteETL`<br> | BlobEvent: `ingestion_ManifestAdded`<br> | Loads Parquet files into Azure Data Explorer<br> |
| 5<br> | Azure Data Explorer — `Hub`<br> | After step 4<br> | Cost records available for query in FOCUS schema<br> |
| 6<br> | Power BI — `Costs` table<br> | DirectQuery on every report interaction<br> | Live cost data served to the semantic model and report<br> |

**Path B — Operational data (Power BI Import refresh)**

All other tables are loaded directly by Power BI on a scheduled refresh — no intermediate pipeline.

| **Source**<br> | **Protocol**<br> | **Tables loaded**<br> |
| --- | --- | --- |
| SharePoint Online<br> | OData<br> | `SP - Azure VMs`<br> |
| Azure Resource Graph / ARM<br> | OAuth2<br> | `VmQueryTOTAL`, `VmQueryUpdate`, `SQL_ManagedIstances`<br> |
| Azure Cost Management<br> | OAuth2<br> | `RI transactions`, `RI usage summary`<br> |

## 3. Data Sources

### 3.1 Azure Cost Management Exports

| **Parameter**<br> | **Value**<br> |
| --- | --- |
| Contract type<br> | Enterprise Agreement (EA)<br> |
| Supported export types<br> | Actual Cost, Amortized Cost, FOCUS 1.x, Reservation Details, Reservation Transactions<br> |
| File format<br> | Parquet (Snappy) or CSV (Gzip)<br> |
| Frequency<br> | Daily (MTD) and Monthly (previous month)<br> |
| Folder structure<br> | `Container/Directory/ExportName/[YYYYMMDD-YYYYMMDD]/[RunID]/`<br> |
| Manifest file<br> | `manifest.json` per run: partitions list, byteCount, dataRowCount, exportConfig<br> |
| Historical data<br> | Up to 13 months via portal, up to 7 years via REST API<br> |

**FOCUS Schema (v1.2-preview) — Key columns used in report**

| **FOCUS Field**<br> | **Description**<br> |
| --- | --- |
| `BilledCost`<br> | Base cost for invoicing (no RI/SP amortization)<br> |
| `EffectiveCost`<br> | Amortized cost (includes RI/SP pro-rated discount)<br> |
| `ContractedCost`<br> | Cost at negotiated prices, excluding RI/SP<br> |
| `CommitmentDiscountId/Name/Type/Status`<br> | Applied Reserved Instance or Savings Plan data<br> |
| `ConsumedQuantity` / `ConsumedUnit`<br> | Consumed quantity and unit of measure<br> |
| `ResourceId` / `ResourceName` / `ResourceType`<br> | Target Azure resource<br> |
| `x_CommitmentDiscountSavings`<br> | Savings generated by RI/SP vs. list price<br> |
| `x_ConsumedCoreHours`<br> | Core-hours consumed (VM-specific)<br> |
| `x_ResourceGroupName` / `x_ResourceType`<br> | ARM resource group and type<br> |
| `x_SkuMeterCategory`<br> | Meter category (e.g., Virtual Machines, SQL Database)<br> |

## 5. ETL Orchestration — Azure Data Factory

### Triggers

| **Trigger**<br> | **Type**<br> | **Schedule / Condition**<br> | **Pipeline**<br> |
| --- | --- | --- | --- |
| `config_DailySchedule`<br> | ScheduleTrigger<br> | Every 24h at 01:01 W.Europe<br> | `config_StartExportProcess` (Recurrence=Daily)<br> |
| `config_MonthlySchedule`<br> | ScheduleTrigger<br> | Days 2, 5, 19 of month at 01:11 W.Europe<br> | `config_StartExportProcess` (Recurrence=Monthly)<br> |
| `config_SettingsUpdated`<br> | BlobEventsTrigger<br> | BlobCreated on `/config/blobs/...settings.json`<br> | `config_ConfigureExports`<br> |
| `msexports_ManifestAdded`<br> | BlobEventsTrigger<br> | BlobCreated on `/msexports/blobs/...manifest.json`<br> | `msexports_ExecuteETL`<br> |
| `ingestion_ManifestAdded`<br> | BlobEventsTrigger<br> | BlobCreated on `/ingestion/blobs/...manifest.json`<br> | `ingestion_ExecuteETL`<br> |

### Key Pipelines

| **Pipeline**<br> | **Purpose**<br> |
| --- | --- |
| `config_StartExportProcess`<br> | Main export start — reads scopes from config, starts export jobs per scope<br> |
| `config_ConfigureExports`<br> | Creates/updates Cost Management exports for each configured scope<br> |
| `config_StartBackfillProcess`<br> | Historical data recovery — iterates month by month over a date range<br> |
| `msexports_ExecuteETL`<br> | Reads manifest, detects EA/MCA channel, maps schema, converts to Parquet Snappy<br> |
| `ingestion_ExecuteETL`<br> | Lists Parquet files in `/ingestion/`, loads each into ADX<br> |

## 9. Glossary

| **Term**<br> | **Definition**<br> |
| --- | --- |
| ADX / Kusto<br> | Azure Data Explorer, columnar analytical database<br> |
| ADLS Gen2<br> | Azure Data Lake Storage Gen2, scalable Big Data storage<br> |
| ADF<br> | Azure Data Factory, Azure ETL/ELT orchestration service<br> |
| EA<br> | Enterprise Agreement, Microsoft enterprise contract for Azure billing<br> |
| FOCUS<br> | FinOps Open Cost and Usage Specification, international standard for cloud cost data<br> |
| ISF<br> | Instance Size Flexibility — RI ability to cover different VM sizes in the same family<br> |
| RI<br> | Reserved Instance, long-term Azure capacity purchase commitment (1 or 3 years)<br> |
| Savings Plan<br> | Flexible compute spend commitment for Azure<br> |
| ResID<br> | Azure Resource ID — unique identifier used to join SharePoint VM registry with live Azure inventory<br> |
| Semantic Model<br> | Power BI data layer with tables, relationships, and DAX measures<br> |
| Parquet Snappy<br> | Columnar compressed file format, optimal for analytics<br> |
